## About the project

A premium, modern and fully responsive café website created as a portfolio demo by **Sati Technologies**. It includes an animated homepage, searchable menu, gallery, offers, reviews, reservation enquiry, contact form, Google Maps and WhatsApp integration.

## Key features

- Responsive layout for mobile, tablet and desktop
- Animated hero and interactive sections
- Searchable and filterable food menu
- Photo gallery with category filters and lightbox
- Premium contact page with map and business hours
- WhatsApp reservation and contact enquiries
- GitHub Pages deployment

## Technology

Next.js • React • JavaScript • Tailwind CSS • Framer Motion • GSAP

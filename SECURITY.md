# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Send a private report to **satitechinfo@gmail.com** with:

- The affected repository and version or commit
- A clear description of the issue and its potential impact
- Safe reproduction steps or a minimal proof of concept
- Any suggested remediation

Do not access, modify, download or retain data that does not belong to you. Stop testing if you encounter personal, customer or production data.

We aim to acknowledge a valid report within five business days. Remediation timing depends on severity and affected systems. Please allow a reasonable remediation period before public disclosure.

## Supported versions

Security fixes are normally applied to the latest maintained release or the current default branch. Individual repositories may publish a more specific support table.

## Secrets found in a repository

If a credential is exposed, report it privately. The credential must be revoked or rotated; deleting it from the latest commit alone is not sufficient.
